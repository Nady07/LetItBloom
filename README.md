#  LetItBloom

> Plataforma para la gestión y promoción de iniciativas de sostenibilidad y cuidado ambiental.

---

## Descripción

**LetItBloom** es una aplicación web desarrollada con React y Vite, diseñada para conectar a personas y organizaciones interesadas en proyectos de sostenibilidad. La plataforma permite visualizar, compartir y gestionar iniciativas ambientales, fomentando la participación ciudadana y el cuidado del planeta.

Este proyecto forma parte de mi portafolio de aplicaciones con enfoque en tecnología para el bien social y la sostenibilidad.

---

## Tecnologías

| Tecnología | Descripción |
|------------|-------------|
| **React** | Biblioteca principal para la interfaz de usuario |
| **Vite** | Build tool ultrarrápida para desarrollo moderno |
| **JavaScript (ES6+)** | Lenguaje de programación principal |
| **CSS3** | Estilos y diseño visual |
| **ESLint** | Herramienta de linting para mantener la calidad del código |

## Instalación y Uso

### Requisitos previos
- Node.js (versión 18 o superior)
- npm o yarn

### Pasos para ejecutar el proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Nady07/LetItBloom.git
   cd LetItBloom
   
2. Instala las dependencias:

bash
npm install
# o con yarn
yarn install

3. Ejecuta el servidor de desarrollo:
   
bash
npm run dev
# o con yarn
yarn dev

Abre tu navegador en: http://localhost:5173
